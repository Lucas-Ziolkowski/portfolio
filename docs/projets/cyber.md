## :material-information: Description

!!! warning "Contexte du projet"

    Nous partons d'une configuration simple d'un parc informatique composé d'un serveur Windows avec Active Directory et de clients Windows 10.

!!! danger "Objectifs du projet"

    Le projet consiste à réaliser des analyses pour détecter :
    
    - :material-shield-alert: Des vulnérabilités
    - :material-bug: Des failles de sécurité
    - :material-cog: Des mauvaises configurations
    - :material-alert-circle: Des mauvaises pratiques de sécurité
    
    L'objectif est de réaliser des exploits permettant de récupérer des comptes à privilèges élevés.

!!! tip "Extension du projet"

    Nous avons également réalisé des exploits sur des machines Linux disposant d'un serveur web.
